# 证据整理

用户要求汇总调查过程或编写详细报告时使用此技能。

1. 先明确目标、范围和观察时间。只使用当前任务已有记录，必要时请求 Agent 调用已授权工具补齐证据。
2. 每个结论关联具体工具调用、记录编号或可访问的来源。没有证据时明确写“尚未验证”。
3. 分开描述已证实事实、推断和失败步骤。工具失败、超时或无输出不能当作目标已完成。
4. 写出复现步骤、实际结果、影响范围、限制及下一步；保留足够细节供他人复核。
5. 输出前检查是否遗漏用户要求，删除令牌、密码、Cookie 和其他凭据。

建议报告结构：目标与范围、结论、证据与过程、失败与限制、后续行动。
如果需要当前 UTC 时间，可在已安装并启用 `catalog_utc_clock` 时调用该工具。
