# FOFA 搜索

## 配置

在「系统设置 → FOFA 资产搜索」填写 API Key，点击「保存并启用」。
也可以仅「保存配置」而不启用；已保存但关闭时，页面会突出显示状态并提供「一键启用 FOFA」。
一键启用仅修改开关，保留已保存 Key 和尚未保存的输入草稿，不发起搜索。
同一卡片可设置请求间隔（1–60 秒，默认 2 秒）和限流冷却（1–3600 秒，默认 60 秒）。
这些默认值是程序的保守设置，不代表 FOFA 官方账户限额。仅修改节流参数不会替换 Key 或改变开关。
只需 API Key，不要求邮箱。「测试连接并查询额度」优先使用当前输入，输入为空时使用已保存的 Key；
只调用账户接口，不发起资产搜索，也不保存草稿。成功后显示 F 点余额、免费 F 点、
API 剩余查询次数、API 剩余返回条数，以及读取时间和本次使用的 Key 来源。

四项分别对应 `fofa_point`、`remain_free_point`、`remain_api_query`、`remain_api_data`，
不会把 `fcoin` 混作 F 点。接口未提供或返回 null 时显示“未提供”，真实零显示 0。
额度仅代表该次读取的快照，页面不自动轮询，也不根据余额猜测后续查询的扣费方式。
修改 Key、保存、清除或重新查询时会清除旧快照；失败或限流不继续显示旧值作为当前余额。
账户响应仅返回这些数值与本地读取元数据，不回显 Key、邮箱、用户名等账户信息，不持久缓存。

留空保存保留旧 Key；输入新 Key 后保存即可更换。「清除 Key 并关闭」会删除已存令牌并禁用工具。
配置读取失败会明确报错，不会假装成未配置。API Key 复用现有 `proxy-secrets` 根密钥，
使用独立 AAD 的 AES-GCM 加密保存。备份和恢复必须一起保留数据库与该密钥文件。

## Agent 与 Skill

`fofa_search`、`fofa_status` 和 `fofa-search` Skill 首次安装默认绑定 `worker`、`auto`、`pentest`。
可以在「工具」修改启用/Agent 绑定，在「Skills」管理技能可见性。
全局开关关闭或未保存 Key 时，运行时不会提供 `fofa_search`，已绑定的 `fofa_status` 仍可查询原因。
两个工具都是原生工具，直接调用；`SearchExtraTools` 没有匹配到延迟工具时也会提示匹配的原生工具及其直接调用方式。
检索无匹配不能证明未配置 Key，历史验收文字也不能代替当前状态。
调用已装配的旧工具会再次检查目录、启用和绑定；搜索还会重读集成开关。
配置保存后下一次工具装配生效，无需重启。主 Agent 保持编排角色，需要查询时派发给 Worker。

`fofa_status({})` 只读取本地配置，不联网、不消耗搜索额度，也不返回 Key。
结果包含 `integration_enabled`、`api_key_set`、`search_tool_enabled`、`agent_bound`、
`search_tool_available` 和 `reason/message`；可用仅表示本地配置及当前 Agent 绑定满足条件，
不代表上游鉴权、剩余额度或出口已经验证。读取失败明确返回错误，不伪装成未配置。
状态还包含 `request_interval_seconds`、`rate_limit_cooldown_seconds`、`retry_after_seconds`；
`request_in_progress` 表示同 Key 正在执行请求，`rate_limited` 表示已进入共享冷却。

技能嵌入二进制，在线更新无需另行复制文件。安装到配置的 SkillDir，安装成功后记录一次性标记；
后续重启不会覆盖用户修改、重新创建被删除技能或恢复已解绑的默认 Agent。
本次内容升级仅替换与旧官方正文摘要匹配的未修改文件，兼容 CRLF；内容迁移不重新执行默认绑定。
文件安装/绑定失败不会登记成功，修正后重启可重试。

## 查询

```json
{"query":"domain=\"example.com\"","page":1,"size":20,"fields":["host","ip","port","protocol"]}
```

- 页码为 1–100，默认 1；每页 1–100 条，默认 20。单次只查一页，不自动重试或翻页。
- 返回 `query/page/size/total/fields/results/has_more`；`total` 是 FOFA 命中总数，`results` 是实际返回的结构化行。
- 支持 `host/ip/port/protocol/domain/title/server/country/country_name/region/city/as_number/as_organization/icp`。
- `fields` 接受最多 14 项字符串数组；省略或空数组使用默认字段，`null` 和非字符串元素会明确报参数错误。
- 固定官方 HTTPS 入口，禁止重定向；30 秒请求上限，响应最多 2 MiB。上游权限与额度限制仍适用。
- 搜索遵守当前任务范围。收录数据可能过期，仅作为线索；不自动访问命中目标、不自动入库，不能单独当作资产归属或漏洞证据。

## 出口与秘密保护

搜索继承正式任务/会话的代理策略和准入引用。只避开本地明文流量录制，仍通过相同出口；
代理不可用时返回错误，不回退直连。请求结束或取消后释放自身 IO 引用。
管理端连接测试固定本次采样的全局代理，并用数据库会话锁与 WARP 维护互斥；不写可能成为孤儿的独立持久活动，进程退出后会话锁释放。不支持没有独立租约生命周期的全局 Resin 账户检测，
此时会明确拒绝请求，实际任务中已有 Resin 租约的搜索仍按任务策略运行。

模型参数、工具结果、配置读取响应与错误不含 API Key。模型调用只提交查询参数，不需要读取任何密钥文件。
搜索错误按鉴权、额度、限流、超时及上游异常分类，不返回可能带令牌的原始请求 URL 或错误正文。

## 共享节流与冷却

所有 Worker、会话和代理出口按同一 API Key 共用数据库节流状态。请求串行执行，间隔排队最多等待 30 秒，并响应任务取消。
许可等待不占用代理 IO 引用；实际发送前重新核验配置、Key 和 Agent 绑定。账户连接测试也经过同一门禁。

HTTP 429 或明确的上游频率拒绝触发持久冷却，取配置冷却与 `Retry-After` 的较长值，支持秒数和 HTTP 日期。
冷却中的请求直接返回结构化 `rate_limited` 与 `retry_after_seconds`，不发起搜索，不自动重放可能计费的请求。
重建客户端、重启程序或换代理不会清除已记录的冷却。程序不因限流轮询代理或刷新 WARP IP。

发送前保存未结算保护，正常完成后才解除。连接中断时会尝试用新数据库连接补写；
若仍无法确认，保留保护并明确返回“停止自动请求”，不能把保存失败当作冷却完成。
异常退出留下的未结算记录需要核对实际请求和数据库后处理，系统不按时间猜测并清除。

本集成使用管理员保存的官方 API Key，不提供未经验证的免 Key 查询入口或“匿名免费版”开关。

## 验证

新增客户端测试只访问本地受控 TLS 服务。数据库测试使用隔离 PostgreSQL；
真实工具链回归覆盖任务代理、开启录制但零凭据流量、结束凭证拒绝、绑定撤销、损坏密钥、取消释放及升级安装。
显式字段回归经过真实装配、参数默认值装饰、权限检查和本地 CONNECT/TLS 上游；
真实 `Chat` 回归覆盖同会话配置变化、工具重新装配及只读状态调用。
前端有 API 测试与 `web/src/lib/fofa-settings.browser.mjs` 浏览器模拟交互脚本。

协议来源：FOFA 官方 `fofapro/fofa-py` 的 `fofa/client.py`（`/api/v1/search/all` 与 `/api/v1/info/my`）。
真实账号权限和额度由用户在设置页配置后，通过连接测试及授权查询核验；自动化测试不会使用生产令牌或扣减真实搜索额度。
